Credentials

A stored credential is a user name with a password or an SSH private key. Operators run jobs with it by name, on the registered targets it is bound to; they never see the secret. A target takes only the types of credential of its kind. A credential for collecting is used only by commands that only read. Only admins may use one for changing.
